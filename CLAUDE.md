## Afronden

Zegt Leen dat iets afgerond is, of "plaats op main": voeg de werkbranch
samen via een pull request op GitHub, nooit rechtstreeks naar main. GitHub
verwijdert de branch na het samenvoegen automatisch, zodat er geen oude
werkbranches blijven slingeren.
